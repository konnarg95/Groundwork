# CampaignIQ v18 — Retention-first dashboard

This release updates the signed-in agent dashboard, retaining the v17 conversion homepage, free login, open-home QR endpoints and existing analysis tools.

## Updates
- Daily workspace header and clear on-device saving status (not a claim of cloud sync).
- Recommended next actions: collect open-home feedback, review comparable sales and prepare seller update.
- Contextual active-property heading with quick edit action.
- Grouped navigation for Property, Campaign and Reporting, including direct Open-home QR entry.
- Mobile-responsive action panel and accessibility focus indicators.

## Important limits
- This version still has one active local property workspace; a true multi-listing cloud-backed campaigns hub is a future feature.
- Browser work is saved locally; cloud saving remains manual.
- QR campaign creation still requires correctly configured Vercel server environment variables and Supabase connectivity.
- Existing prototype metrics and illustrative records are not live market data.

## Deploy
Upload all extracted files to the existing GitHub repository, commit, and wait for Vercel deployment. Sign in, open My dashboard, and check the three quick actions.
